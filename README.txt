PUT YOUR PHOTO HERE
===================

1. Take/choose a clear photo of your face (good light, plain background).
2. Crop it SQUARE (1:1). Size around 600x600 px is perfect.
3. Rename it EXACTLY:  profile.jpg
4. Put it in this same "assets" folder, replacing nothing else.

Done. Refresh the page and your photo appears in the profile card.

If the file is missing or misnamed, the site automatically shows a
"RK" initials circle instead, so nothing ever looks broken.

Tip: keep the file under 300 KB so the site loads fast.
